padshell is a Nintendo Switch homebrew "shell": a set of apps in one process, driven entirely by the gamepad. It has a Gemini browser and a text editor you type into with phone-style multi-tap on the face buttons and D-pad.

padshell is vibe coded: written with an AI coding assistant.
